# Roadmap

Direction, not a delivery promise. The v0.1.0-alpha inference implementation is frozen during release preparation.

| Milestone | Scope |
|---|---|
| v0.1 | SD1.5, measured M5 optimization, local UI, uploaded-image upscaling, distributable alpha |
| v0.2 | M1–M4 compatibility validation, thermal behavior, further UNet profiling |
| v0.3 | Investigate SDXL support |
| v0.4 | Broader LoRA coverage and compatibility testing; v0.1 already supports limited standard SD1.x LoRA |
| v0.5 | Investigate FLUX support |
| v1.0 | Stable public release, wider hardware testing, reliable installation and release signing |

ControlNet and unsupported adapter variants have no committed release date. New model families require separate implementation, memory/performance validation and license review.

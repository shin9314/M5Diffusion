はじめに、モデルを追加してください

画像生成用のモデルは同梱していません。利用する権利のある SD1.5 の .safetensors ファイルを選択してください。すでに Mac にある場合は、下の「Mac 内のファイルをパスで追加」も使えます。

モデルをお持ちでない場合：SD1.5 のモデルカードと取得方法でライセンス・利用条件を確認し、v1-5-pruned-emaonly.safetensors を入手して追加してください。この配布元は元モデルのミラーです。モデルの利用条件はアプリのライセンスとは別です。

初回はモデルの変換が必要です。ファイル保存に加え、少なくとも6 GiB の空き容量を確保してください。高画質化タブは画像生成モデルの追加前でも使用できます。

モデルと LoRA

SD 1.5 系の .safetensors に対応。SDXL / SD 2 / FLUX は使用できません。

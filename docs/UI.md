# ローカル Web UI

デスクトップの `M5Diffusion.app` をダブルクリックすると起動します（Dock に追加すれば1クリック）。既存の `Stable Diffusion.app` とは別です。

プロジェクト内の `start.command` をダブルクリックしても http://127.0.0.1:7861 を開きます。
既存の AUTOMATIC1111 のポート 7860 とは別です。`stop.command` で停止できます。
生成画像とリクエスト、ステージ別の計測結果は `outputs/` に保存します。

SD 1.5、DPM++ 2M / Karras 固定。SDXL / SD 2 / FLUX は対象外です。

「モデルを追加」「LoRAを追加」で .safetensors を選ぶか、種類を選択してファイルをドロップします。複数ファイルを順番に取り込めます。大きなファイルもブラウザのファイル転送機能で送信し、転送状況を表示します。Mac 内の絶対パスを指定して追加することもできます。

モデルはプルダウンから選択。「＋ LoRA を選ぶ」で最大4件の LoRA を重複せず選び、各強度を −2〜2 で設定できます（標準1）。× で選択解除。トリガーワードが必要な LoRA は Prompt に入力してください。選択内容は同じブラウザに保存します。「一覧を更新」で取り込み済みのファイルを再取得できます。

初回のモデル使用時は変換・読み込みに時間がかかる場合があります。形式の不一致や未対応のファイルは画面にエラーを表示します。
最初の生成でモデルを読み込み、同じ専用ワーカースレッド上で再利用します。
生成は直列、待ちキュー最大3件。途中キャンセル・進捗ステップ表示は未実装です。
生成中に停止すると処理中の画像は保存されません。

通常は `.venv/bin/python serve.py` でも起動できます。
比較実験用の環境変数: `M5DIFFUSION_COMPILE=0`（コンパイルを無効化）, `M5_BUFFER_REUSE=0`, `M5_QUANTIZE=4` または `8`。
attention は `M5DIFFUSION_ATTENTION=padded` が既定です。既定はコンパイル有効・バッファ再利用有効・量子化無効です。
`GET /api/health`, `GET /api/library`, `POST /api/library/upload`, `POST /api/library/import`, `POST /api/jobs`, `GET /api/jobs/<id>` が API です。
モデル読み込みも MLX 初期化も最初のジョブまで行わないため、UI 単体確認は GPU を使いません。


## アップロード画像の高画質化

画面上部の「画像を高画質化」を選び、PNG・JPEG・WebPの静止画像を選択またはドロップしてください。「2倍」「4倍」を選んで実行すると、Real-ESRGANで補正して拡大します。処理前後を切り替えて比較し、PNGで保存できます。透明画像の透明度も保持します。画像は外部へ送信しません。

入力は20MB・400万画素以下、出力は1600万画素以下かつ縦横それぞれ4096px以下です。4倍では入力の縦横は1024px以下になります。AIの補正により細部が変わる場合があります。モデルはインストール済みで、通常利用時のダウンロードは不要です。

生成と高画質化は同じ待ち列で順番に実行します。メモリを確保するため、高画質化への切り替え時には生成用モデルを解放します。その後の最初の生成はモデルを再読込します。

API: `POST /api/upscale?scale=2`（または4）、本文は画像ファイルそのもの。返されたidで `GET /api/jobs/<id>` を確認します。画像と処理情報は既存の `outputs/` に保存します。
